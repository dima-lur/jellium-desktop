# Diagnostic capture

The user approved a default resource sampling interval of 5 seconds on
2026-10-31. Capture has no implicit duration: stop manually, close the launched
app, or pass an explicit duration. An override must be positive.

Windows capture records only processes belonging to the selected executable,
identified by PID and creation time. Export numerical counters and fixed role
and action labels only; never command lines, media titles, URLs, or ordinary logs.
Unavailable counters are null, not zero. GPU engines remain separate; their
percentages must not be summed into a misleading overall percentage.

CI validates collection/report contracts and regression tests. It does not certify
leak freedom or impose arbitrary memory/GPU budgets. Hardware playback soak tests
remain a separate, explicitly scheduled activity.
